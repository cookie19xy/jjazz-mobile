## Phase 7: Yamaha 风格文件 SMF 解析器 (今天最大突破)

### 背景
之前 JJazzLab 音质好的原因不是算法，是数据 —— 它播放 Yamaha 键盘风格文件里录好的真实 MIDI 乐句。
我们的 `generate_with_style()` 用的是手写 80 音符循环，差距是数量级的。

### 做了什么

**7a: SMF 解析器**
- 发现 Yamaha 风格文件 (.prs/.sty/.yjz) = 标准 MIDI 文件 + 自定义 Marker
- 添加 `midly` crate, 编写 `style_parser.rs`
- 解析 Marker 分割 StylePart 小节边界
- 提取每轨 NoteOn/NoteOff → 音符列表 (pitch, vel, pos, dur)
- `parse-style` CLI: 一键 dump 风格文件为 JSON

**7b: 真实风格播放**
- `style_player.rs`: 从风格文件加载音符 → SourcePhrase → 和弦适配 → 多轨输出
- `play-style` CLI: `play-style style.yjz Dm7 G7 Cmaj7`
- 修复：每个和弦播放完整 32 拍模式（之前误按 4 拍小节循环）

### 验证
- `psBase.yjz` (149KB) → 4 个 StylePart, 14 个 MIDI 通道
- 单 Part 221 音符, 3 和弦累计 8247 音符 (vs 之前 102)

### 文件
- `src/style_parser.rs` (162 lines) — 新建
- `src/style_player.rs` (97 lines) — 新建
- `src/bin/parse-style.rs` — 新建
- `src/bin/play-style.rs` — 新建
